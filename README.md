Welcome to the official repository for my retro Y2K arcade-themed interactive portfolio, designed and built specifically for an AI and Machine Learning Engineer.

Overview
This portfolio blends a nostalgic 2000s desktop operating system aesthetic with modern technical capabilities. Built using Tailwind CSS and vanilla JavaScript, it features dual-screen navigation, a CRT scanline overlay, interactive modal windows, live clock tracking, and a Nintendo DS-inspired hardware frame featuring my profile photograph (me.jpeg).

How to Run Locally
Clone or download this repository to your local machine.

Ensure your profile photo is named me.jpeg and placed in the exact same directory as your index.html file.

Double-click index.html to open and test the portfolio instantly in any modern web browser.

Deployment (GitHub Pages)
Create a new public repository on GitHub.

Upload both index.html and me.jpeg directly to the repository root.

Navigate to your repository Settings > Pages.

Set the source branch to main (or master) and folder to / (root), then click Save.

Access your live public URL generated by GitHub!
